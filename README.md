# Tecnologia Industrial 2n BATX · Exercicis Plus v1.1

PWA educativa creada com a variant específica de 2n de batxillerat.

## Contingut

- Banc de 615 fitxes detectades i transformades a partir del `Solucionari McGraw 2n BAT.pdf`.
- Classificació per bloc, unitat, tema, tipus i nivell.
- Visualització de la pàgina original renderitzada en JPG.
- Resolució guiada pas a pas.
- Calculadores de suport per a màquines, termodinàmica, oleohidràulica, corrent altern i trifàsica.
- Mode docent, dossiers imprimibles, progrés local i auditoria.

## Avís sobre el contingut

Les fitxes són una transformació didàctica i resumida del material aportat. No substitueixen la revisió docent. Els exercicis amb figures, gràfics o esquemes s'han de revisar amb la pàgina original integrada.

## Desplegament

Puja tots els fitxers a GitHub Pages. Si canvies de versió, esborra la memòria cau o les dades del lloc perquè el Service Worker pot conservar fitxers antics.


## Canvis v1.1

- Tema visual canviat de verd a tons blaus.
- Solucions model depurades: s'amaga el text brut extret i es mostra una versió més llegible.
- Afegit un avís docent quan la solució prové d'extracció automàtica i cal revisar la pàgina original.
- Impressió amb el mateix estil blau i millor lectura de les solucions.

## Limitació real

El PDF original conté fórmules, salts de línia, codis interns i diagrames que no sempre es poden convertir a text perfecte. Aquesta versió millora la lectura, però les activitats amb fórmules o figures complexes s'han de revisar amb la pàgina original integrada.
